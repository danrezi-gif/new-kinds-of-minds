# New Kinds of Minds

**A global atlas of neurodiversity.** A participatory map of the organizations, communities, artistic practices, research groups, support networks, and alternative institutions through which societies are learning to recognize different kinds of minds.

Live: https://new-kinds-of-minds-hub.vercel.app

The map is not only a directory. Put enough verified initiatives on it and patterns appear that no single organization can see from inside: where neurodiversity is chiefly a matter for advocacy and where for care, which forms of neurodivergence have built institutions, where initiatives are led by neurodivergent people and where on their behalf, which vocabularies cross borders. The atlas is an instrument for asking those questions, and a portrait of a movement in the middle of forming.

## What is here

- `data/seed/*.json`: the editable dataset, one file per research pass, every record with a source URL and a verification date. See [data/SCHEMA.md](data/SCHEMA.md) and [data/TAXONOMY.md](data/TAXONOMY.md).
- `data/initiatives.json`, `public/data/initiatives.{json,csv}`: generated by `npm run data`, which also validates every record and fails the build on bad data.
- `app/`: Next.js 15 (App Router, static export). Atlas (`/`), Index table (`/index`), permanent entry pages (`/entry/<id>`), About, Data, and Contribute.
- `components/`: Leaflet map with shape-coded marks, panel and drawer, sortable index, contribution form.
- `server/submissions/`: a dependency-free Node service that queues public submissions as JSONL and pings a Telegram chat. Runs on a small VPS behind Caddy.
- `scripts/pull-submissions.mjs`: fetches the queue and prints draft seed records for review.

## Run it

```bash
npm install
npm run dev        # regenerates the dataset, then starts Next
npm run build      # static export to out/
```

Optional environment: `NEXT_PUBLIC_SUBMIT_ENDPOINT` (URL of the submissions service), `BASE_PATH` (for hosting under a sub-path, e.g. GitHub Pages).

## Contribute an initiative

Use the form at `/contribute`, or add a record to a file in `data/seed/` and open a pull request. Every record must be a real initiative, verifiable at its `source_url`, described in plain terms. Leadership is recorded only when the initiative states it.

## Accessibility

The map is one view. Everything on it is also in the Index as a plain table, and each entry has its own page. Markers are keyboard-focusable, the interface respects `prefers-reduced-motion`, text contrast follows WCAG AA for body copy, and all controls have visible focus states. This is a starting point, not a claim of full accessibility; a professional review is on the roadmap.

## Roadmap

- Latin America mapping phase: several hundred initiatives in Portuguese and Spanish, documented with regional contributors.
- Multilingual interface and summaries (Portuguese, Spanish, English).
- Read-only API and versioned dataset releases.
- Per-record history so corrections are visible; project claiming by the initiatives themselves.
- Network field, so federations and their members can be drawn as links.
- Visual and data essays on the patterns the map shows.
- Professional accessibility review.
